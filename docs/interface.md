## 2. 画面詳細仕様

### 2.1 ログイン画面（SC-001）

#### 2.1.1 概要
- **実装方法**: Amazon Cognito Hosted UI を使用
- **カスタマイズ**: Cognitoコンソールでロゴ・カラー設定のみ
- **機能**:
  - ログイン
  - サインアップ
  - パスワードリセット
  - MFA（オプション）

#### 2.1.2 Cognito設定要件
- ロゴ: アプリケーションロゴを設定
- アプリクライアント名: "ログ解析システム"
- コールバックURL: `https://<domain>/dashboard`
- サインアウトURL: `https://<domain>/`

#### 2.2.3 会話履歴サイドバー（SB-001）

| 要素ID | 要素名 | タイプ | 説明 |
|--------|--------|--------|------|
| SB-001 | 新規会話ボタン | ボタン | 新しい会話を開始 |
| SB-002 | 履歴リスト | リスト | 過去の会話一覧 |
| SB-003 | 履歴項目 | リストアイテム | 個別の会話履歴 |
| SB-004 | 削除ボタン | アイコンボタン | 履歴削除（ホバー時表示） |

**履歴項目の表示形式**
```
📅 2024/01/15 10:23
Q: 過去24時間のエラーログを表示
```

**動作仕様**
- 履歴項目クリック: その会話の内容を復元
- 削除ボタンクリック: 確認ダイアログ表示後削除
- 最大表示件数: 50件（古いものから自動削除）
- 保存場所: ブラウザのlocalStorage

**新規会話ボタン動作**
1. 現在の会話をクリア
2. 日付範囲をデフォルト（過去24時間）にリセット
3. 入力欄をクリア

#### 2.2.4 日付範囲選択（DR-001）

| 要素ID | 要素名 | タイプ | 説明 |
|--------|--------|--------|------|
| DR-001 | 開始日 | 日付ピッカー | 検索開始日 |
| DR-002 | 終了日 | 日付ピッカー | 検索終了日 |
| DR-003 | プリセット選択 | ドロップダウン | 定型期間選択 |
| DR-004 | 適用ボタン | ボタン | 日付範囲を確定 |
| DR-005 | データサイズ表示 | テキスト | 推定データサイズ表示 |

**プリセットオプション**
- 過去1時間
- 過去24時間（デフォルト）
- 過去7日間
- 過去30日間
- カスタム範囲

**バリデーション**
- 開始日 ≤ 終了日
- 最大範囲: 30日間
- 未来の日付は選択不可
- 推定データサイズが1GBを超える場合は警告

**エラーメッセージ**
- "開始日は終了日より前に設定してください"
- "最大30日間まで選択可能です"
- "⚠️ 推定データサイズが1GBを超えています。範囲を狭めることを推奨します"

**データサイズ表示例**
```
推定データサイズ: 約 450 MB
```

#### 2.2.5 自然言語入力（NL-001）

| 要素ID | 要素名 | タイプ | 説明 |
|--------|--------|--------|------|
| NL-001 | 質問入力欄 | テキストエリア | 自然言語での質問 |
| NL-002 | 送信ボタン | ボタン | クエリ実行 |
| NL-003 | ローディング表示 | スピナー | 処理中表示 |
| NL-004 | サジェスト | ドロップダウン | 質問例の提示 |
| NL-005 | 会話コンテキスト表示 | バッジ | 会話継続中の表示 |

**入力仕様**
- 最大文字数: 500文字
- Enter キー: 送信（Shift+Enter: 改行）
- プレースホルダー: "ログについて質問してください（例：過去24時間のエラーログを表示）"
- 自動リサイズ: 入力内容に応じて高さ調整

**サジェスト例（初回質問時）**
- "過去24時間のエラーログを表示"
- "最も遅いエンドポイントトップ10"
- "今日のログレベル別件数"
- "エラー率の推移をグラフで表示"
- "サービス別のリクエスト数を円グラフで"

**会話コンテキスト表示**
```
💬 会話継続中 (3/10)
```
- 会話の深さを表示
- 10ターン以上で警告（コンテキストが長すぎる）

**動作仕様**
1. 質問入力
2. 送信ボタン押下
3. ローディング表示（"SQLを生成中..."）
4. Route Handler経由でBedrock API呼び出し
5. SQL生成（2-5秒）
6. SQL表示
7. ローディング表示更新（"ログを読み込み中..."）
8. DuckDB WASM実行（5-30秒）
9. 結果表示（グラフ + テーブル）
10. 会話履歴に追加

**エラーハンドリング**
- ネットワークエラー: "接続に失敗しました。再試行してください"
- SQL生成失敗: "質問を理解できませんでした。別の表現で試してください"
- クエリ実行失敗: "クエリの実行に失敗しました。SQLを確認してください"
- タイムアウト: "処理に時間がかかりすぎています。日付範囲を狭めてください"

**表示仕様**
- シンタックスハイライト（SQL用）
- 折りたたみ可能（デフォルト: 展開）
- 行番号表示
- ダークモード対応

**編集モード**
- SQL-002クリックで編集可能に
- モナコエディタまたはシンプルなテキストエリア

**コピー機能**
- SQL-003クリックでクリップボードにコピー
- トースト通知: "SQLをコピーしました"

**グラフタイプ**

##### 時系列グラフ（折れ線グラフ）
```
用途: ログレベル別の推移、エラー数の時系列変化

表示例:
  件数
   ↑
500│        ╱╲
400│       ╱  ╲    ╱╲
300│   ╱╲╱    ╲  ╱  ╲
200│  ╱         ╲╱    ╲
100│╱                  ╲
   └────────────────────→ 時間
    10:00  12:00  14:00  16:00

凡例: ━ ERROR  ━ WARN  ━ INFO
```

**機能**
- 複数系列の表示（最大5系列）
- ズーム: マウスホイール、ピンチ
- パン: ドラッグ
- ツールチップ: 正確な値表示
- X軸: 時間（自動スケール調整）
- Y軸: 件数（自動スケール調整）

**ドリルダウン**
- データポイントクリック
- 該当時間帯の詳細クエリを自動生成
- 例: "2024-01-15 10:00-11:00のERRORログの詳細"

##### 円グラフ
```
用途: ログレベルの割合、サービス別の分布

表示例:
      ╱────╲
    ╱   45% ╲
   │  ERROR  │
   │         │╲
   │   30%   │ ╲ 25%
   │  WARN   │  │INFO
    ╲       ╱  ╱
      ╲────╱──╱
```

**機能**
- パーセンテージ表示
- 凡例表示（クリックで表示/非表示）
- セグメントのハイライト（ホバー時）
- ラベル表示（件数 + パーセンテージ）
- 最大セグメント数: 10（それ以上は"その他"にまとめる）

**ドリルダウン**
- セグメントクリック
- そのカテゴリのログ一覧を表示
- 例: "ERRORログの詳細を表示"

##### 棒グラフ
```
用途: エンドポイント別リクエスト数、レスポンスタイム比較

表示例:
  リクエスト数
   ↑

400│     ████  ████
300│     ████  ████  ████
200│     ████  ████  ████  ████
```

- 横棒・縦棒の切り替え
- ソート機能（昇順・降順）
- グループ化（積み上げ棒グラフ）
- 最大表示数: 20項目
- スクロール対応（20項目以上の場合）

**ドリルダウン**
- バークリック
- そのカテゴリの時系列分析
- 例: "/api/usersエンドポイントの時系列推移"

**カラム表示**

デフォルト表示カラム:
- timestamp（必須、非表示不可）
- level
- service
- message（省略表示、クリックで全文）
- user_id
- endpoint

オプションカラム（カラム設定で表示/非表示）:
- duration_ms
- status_code
- method
- error
- trace_id
- ip_address
- request_id

**ソート機能**
- カラムヘッダークリックでソート
- 昇順 ↑ / 降順 ↓ / ソートなし
- 複数カラムソート対応（Shiftキー + クリック）
- デフォルト: timestamp降順

**ページネーション**
- 表示件数オプション: 10 / 50 / 100 / 500 件
- ページ番号表示: [< 1 2 3 ... 25 >]
- 前へ/次へボタン
- ページジャンプ入力欄

**検索フィルタ**
- リアルタイム検索（入力中に絞り込み）
- 全カラム対象
- 大文字小文字区別なし
- 正規表現対応（オプション）

**行選択**
- チェックボックスで複数行選択
- 全選択/全解除ボタン
- 選択行に対する一括操作:
  - CSVエクスポート
  - 詳細表示
  - グラフ化

**CSVエクスポート**
- 現在の表示データをエクスポート
- 全データエクスポート（最大10,000件）
- 選択行のみエクスポート
- ファイル名: `logs_YYYYMMDD_HHmmss.csv`

**行クリック動作**
- 行クリックで詳細モーダル表示
- モーダル内容:
  - 全フィールド表示
  - JSON形式表示切替
  - 関連ログ表示（同じtrace_id）
  - コピーボタン

**レスポンシブ対応**
