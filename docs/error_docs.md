# ログ解析システム エラーハンドリング仕様書

## 1. エラー分類

### 1.1 エラーカテゴリ

| カテゴリ | プレフィックス | 説明 | 重要度 |
|---------|--------------|------|--------|
| 認証エラー | AUTH | 認証・認可関連 | 高 |
| ネットワークエラー | NET | 通信関連 | 高 |
| SQLエラー | SQL | SQL生成・実行関連 | 中 |
| データエラー | DATA | データ読み込み・処理関連 | 中 |
| DuckDBエラー | DUCKDB | DuckDB WASM関連 | 高 |
| エクスポートエラー | EXPORT | ファイル出力関連 | 低 |
| バリデーションエラー | VALID | 入力検証関連 | 低 |
| システムエラー | SYS | その他システムエラー | 高 |

---

## 2. エラーコード一覧

### 2.1 認証エラー（AUTH）

| コード | メッセージ | 原因 | ユーザー対処 | システム対処 |
|--------|-----------|------|------------|------------|
| AUTH-001 | 認証が切れました | セッションタイムアウト | 再ログイン | Cognito Hosted UIへリダイレクト |
| AUTH-002 | アクセス権限がありません | チーム権限不足 | 管理者に連絡 | 403エラー、ログ記録 |
| AUTH-003 | ログインに失敗しました | 認証情報不正 | 入力内容を確認 | エラーメッセージ表示 |
| AUTH-004 | アカウントがロックされています | 連続ログイン失敗 | 15分後に再試行 | ロック解除待機 |
| AUTH-005 | トークンの検証に失敗しました | トークン改ざん・期限切れ | 再ログイン | トークン再取得 |

### 2.2 ネットワークエラー（NET）

| コード | メッセージ | 原因 | ユーザー対処 | システム対処 |
|--------|-----------|------|------------|------------|
| NET-001 | ネットワーク接続に失敗しました | ネットワーク切断 | 接続確認後再試行 | 自動リトライ（3回） |
| NET-002 | サーバーに接続できません | サーバーダウン | 時間をおいて再試行 | 503エラー、アラート送信 |
| NET-003 | タイムアウトしました | レスポンス遅延 | 再試行 | タイムアウト時間延長 |
| NET-004 | リクエストが大きすぎます | ペイロードサイズ超過 | データ量を減らす | 413エラー |
| NET-005 | レート制限に達しました | API呼び出し過多 | 時間をおいて再試行 | 429エラー、待機時間表示 |

### 2.3 SQLエラー（SQL）

| コード | メッセージ | 原因 | ユーザー対処 | システム対処 |
|--------|-----------|------|------------|------------|
| SQL-001 | SQLの生成に失敗しました | Bedrock API エラー | 別の表現で再試行 | エラーログ記録、フォールバック |
| SQL-002 | SQLの実行に失敗しました | 構文エラー | SQLを確認・修正 | エラー詳細表示 |
| SQL-003 | クエリがタイムアウトしました | 処理時間超過（60秒） | 日付範囲を狭める | クエリキャンセル |
| SQL-004 | 危険なSQLが検出されました | DROP/DELETE等 | - | SQL実行拒否、ログ記録 |
| SQL-005 | team_idフィルタが不足しています | セキュリティ違反 | - | SQL自動修正または拒否 |
| SQL-006 | カラムが存在しません | 不正なカラム名 | カラム名を確認 | 利用可能カラム一覧表示 |
| SQL-007 | 構文エラーです | SQL文法エラー | SQLを修正 | エラー箇所ハイライト |

### 2.4 データエラー（DATA）

| コード | メッセージ | 原因 | ユーザー対処 | システム対処 |
|--------|-----------|------|------------|------------|
| DATA-001 | データサイズが大きすぎます | 1GB超過 | 日付範囲を狭める | 警告表示、読み込み中止 |
| DATA-002 | ログファイルが見つかりません | S3にデータなし | 日付範囲を確認 | 404エラー |
| DATA-003 | ログの読み込みに失敗しました | S3アクセスエラー | 権限確認・再試行 | S3エラーログ記録 |
| DATA-004 | ファイル形式が不正です | 非JSONL形式 | - | エラーログ記録、管理者通知 |
| DATA-005 | データの解凍に失敗しました | GZIP破損 | - | 別ファイル試行、エラー記録 |
| DATA-006 | データが空です | 該当データなし | 条件を変更 | 空結果メッセージ表示 |
| DATA-007 | データの解析に失敗しました | JSON形式エラー | - | エラー行スキップ、ログ記録 |

### 2.5 DuckDBエラー（DUCKDB）

| コード | メッセージ | 原因 | ユーザー対処 | システム対処 |
|--------|-----------|------|------------|------------|
| DUCKDB-001 | DuckDBの初期化に失敗しました | ブラウザ非対応 | 最新ブラウザを使用 | 対応ブラウザ一覧表示 |
| DUCKDB-002 | メモリ不足です | ブラウザメモリ制限 | タブを閉じて再試行 | メモリ使用量警告 |
| DUCKDB-003 | WebAssemblyの読み込みに失敗しました | WASM読み込みエラー | ページ再読み込み | エラーログ記録 |
| DUCKDB-004 | データベース接続に失敗しました | Connection エラー | 再試行 | 自動再接続 |
| DUCKDB-005 | トランザクションエラーです | 同時実行エラー | 再試行 | トランザクションロールバック |

### 2.6 エクスポートエラー（EXPORT）

| コード | メッセージ | 原因 | ユーザー対処 | システム対処 |
|--------|-----------|------|------------|------------|
| EXPORT-001 | CSVのエクスポートに失敗しました | ファイル書き込みエラー | 再試行 | エラーログ記録 |
| EXPORT-002 | ファイルサイズが大きすぎます | 100MB超過 | データ量を減らす | エクスポート中止 |
| EXPORT-003 | ダウンロード権限がありません | ブラウザ権限不足 | ダウンロード許可 | 権限リクエスト |

### 2.7 バリデーションエラー（VALID）

| コード | メッセージ | 原因 | ユーザー対処 | システム対処 |
|--------|-----------|------|------------|------------|
| VALID-001 | 日付範囲が不正です | 開始日 > 終了日 | 日付を修正 | インラインエラー表示 |
| VALID-002 | 日付範囲が大きすぎます | 30日超過 | 範囲を狭める | 最大範囲表示 |
| VALID-003 | 未来の日付は選択できません | 未来日付選択 | 過去日付を選択 | 日付ピッカー制限 |
| VALID-004 | 入力が空です | 必須項目未入力 | 入力してください | 必須マーク表示 |
| VALID-005 | 文字数制限を超えています | 500文字超過 | 文字数を減らす | 文字数カウンター表示 |
| VALID-006 | 不正な文字が含まれています | 特殊文字使用 | 文字を修正 | 許可文字一覧表示 |

### 2.8 システムエラー（SYS）

| コード | メッセージ | 原因 | ユーザー対処 | システム対処 |
|--------|-----------|------|------------|------------|
| SYS-001 | 予期しないエラーが発生しました | 不明なエラー | ページ再読み込み | エラーログ記録、アラート |
| SYS-002 | ブラウザがサポートされていません | 古いブラウザ | ブラウザ更新 | 対応ブラウザ案内 |
| SYS-003 | 機能が一時的に利用できません | メンテナンス中 | 時間をおいて再試行 | メンテナンス情報表示 |
| SYS-004 | セッションストレージが利用できません | ストレージ無効 | ブラウザ設定確認 | 代替手段提示 |

## 3. エラー表示パターン

### 3.1 インラインエラー

**用途**: 入力フィールドのバリデーションエラー

**表示位置**: 該当入力フィールドの直下

**表示形式**:
```
┌────────────────────────────────┐
│ 開始日                          │
│ [2024/01/20________________]   │
│ ✕ 未来の日付は選択できません    │
└────────────────────────────────┘
```

**スタイル**:
- アイコン: ✕（赤）
- テキスト色: #EF4444（赤）
- フォントサイズ: 14px
- 表示タイミング: リアルタイム（入力中）

**実装例**:
```typescript
interface InlineError {
  fieldId: string;
  errorCode: string;
  message: string;
  show: boolean;
}
```

### 3.2 トーストエラー

**用途**: 一時的な通知、軽微なエラー

**表示位置**: 画面右上

**表示時間**:
- 成功: 3秒
- 情報: 5秒
- 警告: 7秒
- エラー: 10秒（または手動で閉じるまで）

**表示形式**:
```
┌────────────────────────────────┐
│ ✕ ネットワーク接続に失敗        │
│   NET-001                      │
│   [再試行] [×]                 │
└────────────────────────────────┘
```

**スタイル**:
- 背景色: 白
- ボーダー: 左側4px（エラー色）
- シャドウ: shadow-lg
- 最大幅: 400px
- アニメーション: スライドイン（右から）

**タイプ別スタイル**:
```
成功: 緑ボーダー (#10B981)
情報: 青ボーダー (#3B82F6)
警告: オレンジボーダー (#F59E0B)
エラー: 赤ボーダー (#EF4444)
```

**実装例**:
```typescript
interface ToastError {
  id: string;
  type: 'success' | 'info' | 'warning' | 'error';
  errorCode?: string;
  message: string;
  duration: number;
  action?: {
    label: string;
    onClick: () => void;
  };
}
```

### 3.3 モーダルエラー

**用途**: 詳細情報が必要な重要エラー、ユーザーアクションが必要

**表示位置**: 画面中央

**表示形式**:
```
┌─────────────────────────────────────────┐
│ ⚠️ SQLの実行に失敗しました              │
│                                         │
│ エラーコード: SQL-002                   │
│ 発生時刻: 2024-01-15 10:23:45          │
│                                         │
│ エラー詳細:                              │
│ ┌─────────────────────────────────┐    │
│ │ Syntax error: Unknown column    │    │
│ │ 'user_name' at line 3           │    │
│ └─────────────────────────────────┘    │
│                                         │
│ 生成されたSQL:                           │
│ ┌─────────────────────────────────┐    │
│ │  1  SELECT user_name, COUNT(*)  │    │
│ │  2  FROM logs                   │    │
│ │  3  WHERE level = 'ERROR'       │ ← │
│ │  4  GROUP BY user_name          │    │
│ └─────────────────────────────────┘    │
│                                         │
│ 対処方法:                                │
│ • SQLを確認して修正してください          │
│ • カラム名は 'user_id' です             │
│ • スキーマを確認する場合は              │
│   [スキーマを表示] をクリック            │
│                                         │
│ [スキーマを表示] [SQLを編集] [閉じる]   │
└─────────────────────────────────────────┘
```
